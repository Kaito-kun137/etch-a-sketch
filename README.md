# 🎨 Etch-A-Sketch

A responsive, browser-based drawing grid built with vanilla HTML, CSS, and JavaScript. This project demonstrates dynamic DOM manipulation, event handling, and custom grid generation.


---

## ✨ Features

* **Interactive Drawing:** Hover or drag over grid squares to leave a trail of color.
* **Dynamic Grid Sizing:** Users can click a button to enter a custom grid resolution (e.g., 16x16 up to 100x100).
* **Color Modes:**
  * 🖤 **Classic:** Standard black-on-white sketchpad.
  * 🌈 **Rainbow Mode:** Generates random RGB colors on hover for a colorful effect.
  * 🌑 **Shading/Opacity Mode:** Gradually darkens pixels with each pass to simulate progressive drawing.
* **Clear Canvas:** Easily reset the board to start a new creation.

---

## 🛠️ Built With

* **HTML5:** Semantic structure and layout containers.
* **CSS3:** Flexbox / CSS Grid, custom properties, and smooth transitions.
* **JavaScript (ES6):** Dynamic DOM creation, event listeners (`mouseover`, `click`), and conditional logic.

---

## 🧠 Concepts Learned & Applied

* **DOM Manipulation:** Dynamically creating, appending, and clearing DOM elements on the fly rather than hardcoding HTML.
* **Event Delegation & Handling:** Working with mouse events like `mouseover`, `mouseenter`, and `click`.
* **CSS Grid & Flexbox Layouts:** Programmatically adjusting grid layout dimensions based on user input.
* **State Management:** Keeping track of current active drawing modes (Rainbow, Shader, Eraser) in JavaScript.
